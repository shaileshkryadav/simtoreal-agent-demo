# SimToReal Agent recorded demo

Public presentation assets for Visionary Creators, AMD Developer Hackathon: ACT III, Intelligent Industry.

The page shows recorded October 16, 2026 AMD Token Factory runs with local MuJoCo simulation. It does not run inference or command a robot in the browser.

Source project: https://github.com/anish-01/simtoreal-agent

The demo video includes synthesized narration. Run records under evidence/ remove local absolute paths. No API keys are included.

Serve this directory with any static HTTP server. GitHub Pages publishes the main branch root.
