Evidence before approval

A valid JSON plan can still drop a part. SimToReal Agent gives robotics engineers and factory operators a way to inspect candidate plans in a simulated pick-and-place scene.

  1. Describe a task. AMD-hosted inference extracts goals and generates eight JSON plans.
  2. Run independent simulations. Each plan gets a Panda arm scene, a video and a final image.
  3. Reject measured failures. Check task completion, failed actions, arm-table collisions and dropped parts before ranking.
  4. Review and approve an export. Camera disagreement requires acknowledgement. Approval produces JSON and readable steps.

The prototype exports files. It does not command a physical robot.

Camera uncertainty stays visible

Both successful task runs passed geometry checks but received a “no” camera response. The overhead view can hide a part behind the arm. Both responses triggered human review before export.

Model confidence does not establish correctness. The operator must inspect the video and final image.

Where AMD runs

Planning: DeepSeek-V4-Flash
Image review: DeepSeek-V4.1-Flash
Inference service: shared AMD Token Factory

Local MuJoCo uses four simulation workers. The shared API does not report GPU SKU, ROCm version or server-side GPU timing. We do not claim measured MI300X performance.

A working prototype, ready for review

The project has 111 passing tests and an operator page with session results, media review and approval exports. The next step is a robotics-engineer pilot to improve camera visibility, broaden collision checks and measure operator setup time. Factory savings remain unmeasured.

Run the interactive application locally

Use Python 3.12 and your own endpoint credentials. The repository README explains installation and AMD Token Factory configuration.

python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-ui.txt
cp .env.tokenfactory.example .env
# Set your own LLM_API_KEY locally in .env
.venv/bin/python app.py

Open http://127.0.0.1:7860. To run real simulations with saved plans and no model inference:

PYTHON_DOTENV_DISABLED=1 SIM_WORKERS=4 .venv/bin/python scripts/demo_tasks.py
